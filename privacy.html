Privacy Policy

Last updated: 2026-10-07

Higgs Video Uploader ("the tool") is a private command-line tool operated by an independent developer (higgs1729, "we"). It is used only by the developer to manage the developer's own YouTube channels.

YouTube API Services

The tool uses YouTube API Services. By using the tool, users agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Information we access, collect and store

  • Google OAuth tokens for the channel owner's Google accounts. They are stored only on the developer's own computer and are used only to call YouTube API Services on behalf of that owner.
  • Data of the owner's own channels and videos returned by the YouTube Data API and YouTube Analytics API (for example video IDs, titles, privacy status and view statistics). It is used to confirm uploads and to review the performance of the owner's own videos.
  • The tool does not access, collect or store data about any other YouTube users. It does not use cookies or tracking technologies, and this website does not collect any personal information.

How we use and share information

Information is used only to upload and manage the owner's own videos. We do not sell, share or disclose it to any third party. The only external service the tool communicates with is Google (YouTube API Services).

Storage and deletion

  • Data obtained from YouTube API Services is stored only on the developer's computer. It is refreshed or deleted within 30 days, except for statistics the developer keeps for the developer's own channels.
  • Users can revoke the tool's access to their Google account at any time from the Google security settings page: https://security.google.com/settings/security/permissions. After access is revoked, the stored tokens can no longer be used and are deleted.
  • To request deletion of any stored data, contact us at the address below. We will delete it within 7 days.

Changes

We may update this policy. The date at the top shows the latest version.
